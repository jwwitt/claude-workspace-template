# Inbox

Raw material lands here. Nothing here is a note yet.

Captures are named `YYYY-MM-DD-<slug>.md` and are written by
[`/capture`](../../../.claude/skills/capture/SKILL.md), or by hand from any
device. Drop things in freely — capture is cheap, and the gate that matters is
on what leaves here, not on what arrives.

Clearing this directory is [`/pkm-triage`](../../../.claude/skills/pkm-triage/SKILL.md),
which is user-invoked: nothing empties it on its own, so a pile-up is normal
rather than a problem. Every capture leaves with one verdict — promoted into
`notes/`, folded into an existing note, routed to a backlog as work, or
discarded.

## Why this file exists

**An empty directory does not sync.** The vault replicates file by file, so a
directory holding only `.gitkeep` is invisible on every other device — and
because triage exists to empty this one, the inbox would disappear from the
phone at exactly the moment the next capture was due. This file is permanent
furniture that keeps the directory real everywhere. Triage ignores it by name.
